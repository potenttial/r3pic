# R3Pic

**ES:** R3Pic es una herramienta de N3 Labs, desarrollada en alianza con The 1% of Financial Leaders, que entrega fotos de eventos por reconocimiento facial. El asistente escanea un código QR, da su consentimiento, se toma una selfie y recibe las fotos donde aparece.

**EN:** R3Pic is an N3 Labs tool, built in alliance with The 1% of Financial Leaders, that delivers event photos using face recognition. Attendees scan a QR code, give consent, take a selfie, and get the photos they appear in.

## Demo

- Asistente / Attendee: `#asistente`
- Fotógrafo / Photographer: `#fotografo`

Para cargar un evento: abre `#fotografo`, agrega fotos, descarga `event.json` y súbelo a la raíz de este repositorio.

**Aviso:** este repositorio es público, así que `event.json` también lo es. Incluye las fotos y los datos faciales del evento. Úsalo solo con fotos de prueba de personas que lo hayan autorizado, nunca con un evento real.
